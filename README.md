
# Week 6 - Fetch CRUD Posts Manager

## Description
A simple CRUD Posts Manager built with Vite, JavaScript, Tailwind CSS, and JSONPlaceholder API.

This project allows users to manage posts using the Fetch API.

## Technologies Used
- HTML
- CSS
- JavaScript (ES Modules)
- Vite
- Tailwind CSS
- Fetch API
- JSONPlaceholder API

## Features
- Fetch and display 10 posts.
- Filter posts by user (1-10).
- Create new posts.
- Edit post titles.
- Delete posts with confirmation.
- Handle loading and error states.
- 8-second request timeout.

## Installation

1. Clone the repository:

```bash
git clone [YOUR_GITHUB_REPOSITORY_URL](https://github.com/Neema2023/week6-fetch-crud.git)
```

2. Navigate to the project folder:

```bash
cd week6-fetch-crud
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite.

## API Used
https://jsonplaceholder.typicode.com/posts

## Note
JSONPlaceholder is a fake REST API. POST, PATCH, and DELETE requests simulate server operations but do not permanently save changes.
